# Security Testing Labs

Hands-on vulnerable web applications, CTF platforms, and practice labs for penetration testers and bug bounty hunters. Practicing in legal, deliberately vulnerable environments is essential for building exploit reproduction and triage skills.

## Online Interactive Practice Platforms

| Platform | Type | Focus | Link |
| :--- | :--- | :--- | :--- |
| **PortSwigger Web Security Academy** | Free Interactive Labs | Web vulnerabilities, modern browser attacks, HTTP smuggling, OAuth, JWT, race conditions | [portswigger.net/web-security](https://portswigger.net/web-security) |
| **TryHackMe** | Guided Cloud VMs | Beginner-to-intermediate paths, web fundamentals, network pivoting | [tryhackme.com](https://tryhackme.com/) |
| **Hack The Box (HTB)** | Cloud Labs & Machines | CTF challenges, realistic AD & web exploit chains, enterprise labs | [hackthebox.com](https://hackthebox.com/) |
| **PentesterLab** | Subscription Labs | Deep-dive code reviews, Unix/web exploitation, modern bypasses | [pentesterlab.com](https://pentesterlab.com/) |
| **PicoCTF** | Free Gamified CTF | Security fundamentals, binary exploitation, web exploitation | [picoctf.org](https://picoctf.org/) |
| **OverTheWire** | SSH Wargames | Linux command line basics (Bandit), web vulnerabilities (Natas) | [overthewire.org](https://overthewire.org/) |

| :--- | :--- | :--- | :--- |
